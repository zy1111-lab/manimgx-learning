# ManimGX 开荒：第一课

## 目标
复现上游 README 的 Hello3D：画出立方体，并让相机围绕它旋转。
上游：https://github.com/academa-labs/manimgx

## 环境
- Windows，Python 3.13.15
- 独立环境：项目根目录的 .venv
- 安装来源：清华 PyPI 镜像（官方下载发生超时后切换）
- 使用发布版运行示例；尚未编译 Rust 源码，也未验证上游性能指标。

## 自己再运行一次
在项目根目录打开 PowerShell：

```powershell
.\.venv\Scripts\manimgx.exe render .\outputs\scene.py
```

首次运行后，终端会给出视频路径。

## 逐行读代码
1. `import manimgx as m`：导入动画库，给它取一个简短名称 m。
2. `class Hello3D(m.ThreeDScene)`：定义一个三维场景，继承库提供的能力。
3. `def construct(self)`：场景内容写在这里；缩进表示哪些语句属于这个方法。
4. `set_camera_orientation`：设置相机观察物体的角度。
5. `begin_ambient_camera_rotation`：让相机持续转动，rate 控制旋转速度。
6. `m.Cube(...)`：创建立方体，设置边长、透明度和边线宽度。
7. `self.play(m.Create(cube), run_time=2)`：用两秒钟播放立方体出现的动画。
8. `self.wait(4)`：再保留四秒钟；相机继续转动。
